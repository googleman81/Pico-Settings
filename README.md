# Pico-Settings-1.0.0
Customization and additional settings for the Pico 4.

First hardware-test release of a tiny, unofficial Android Settings launcher for
the consumer PICO 4.

Included shortcuts

Full Android Settings

Private DNS

Wi-Fi

VPN

Installed apps

Developer options

Display

Device information

Security properties

No requested Android permissions

No network or storage access

No background service, boot receiver, accessibility service, or VPN service

No analytics or third-party application libraries

Some individual Android panels may be absent or blocked by a particular PICO OS
release. In that case, the app falls back to Full Android Settings.

Install with:

adb install -r PicoSettings-v1.0.0.apk
